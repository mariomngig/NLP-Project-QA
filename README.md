<h2>Arabic Extractive Question Answering Web App</h2>  

-	Built a functional Arabic Question Answering system by fine-tuning AraBERT model from Hugging Face Transformers.
-	Employed the Farasa Segmenter for Arabic-specific preprocessing (segmentation/desegmentation), enabling effective handling of rich morphology and diacritics.
-	Developed an interactive web application using Streamlit, allowing users to input Arabic context and questions and receive real-time answers from the model.
-	Integrated end-to-end NLP pipeline: segmentation → tokenization → model inference → desegmentation and answer display.
